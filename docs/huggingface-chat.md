# Hugging Face chatbot setup

The chatbot searches public website content and asks a Hugging Face model to write a concise reply using that search result. Source links are supplied by Laravel, not generated by the model. Each question is independent; conversation history is not sent.

1. Create a fine-grained token at https://huggingface.co/settings/tokens with **Make calls to Inference Providers** permission.
2. Add these settings to your local/deployment `.env` (never put the token in JavaScript or commit it):

   ```dotenv
   HF_TOKEN=your_token_here
   HF_MODEL=openai/gpt-oss-120b:cheapest
   ```

3. Run `php artisan config:clear`.
4. Open the chatbot and ask a website question. Successful AI replies show an AI-generated label. Without credentials, or if the provider fails, the existing website search answer remains available.

You can replace `HF_MODEL` with a chat-completion model supported by Inference Providers. The `:cheapest` suffix selects the lowest-cost provider; it does **not** mean unlimited free inference. Free accounts currently receive $0.10 monthly credits, subject to change. To stay on the free allowance, do not purchase credits or enable paid billing/custom paid provider keys. The application does not track your Hugging Face account balance; it falls back when requests are rejected.

Visitor questions and the retrieved public website text are sent to Hugging Face and its selected inference provider. API tokens stay server-side. Requests have a timeout and use the existing `/chat` rate limit. Model answers can still be inaccurate; they are not bookings or official quotations.

Check `storage/logs/laravel.log` for sanitized provider status codes: 401/403 generally mean token/permission issues, 402 can indicate credits, 429 means throttling, and 400/404 can indicate an unsupported model. Do not disable TLS certificate verification to resolve local PHP certificate issues.

Documentation: https://huggingface.co/docs/inference-providers/index and https://huggingface.co/docs/inference-providers/pricing

Verification: `php tests/huggingface_chat_smoke.php` uses fake HTTP responses and makes no paid API calls. `php tests/chat_smoke.php` checks the existing public-content search.
